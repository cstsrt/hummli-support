# Hummli Support

Public support and privacy pages for the Hummli iPhone app.

The support page embeds a public Google Form. Responders do not need a Google or GitHub account, and the developer email address is not exposed.

- Privacy: https://cstsrt.github.io/hummli-support/privacy/
- Support: https://cstsrt.github.io/hummli-support/support/
